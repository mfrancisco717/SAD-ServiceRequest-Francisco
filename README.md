# ICT Service Request Management System

## Systems Analysis and Design

This project is an Online ICT Service Request Management System developed using:

- HTML
- CSS
- JavaScript
- Supabase
- PostgreSQL
- GitHub
- GitHub Pages

## Features

- User Login
- User Logout
- Dashboard
- Create Service Request
- View Service Requests
- Update Service Request
- Delete Service Request
- Search Requests
- Filter Requests
- Filter by Priority
- Service Request Status

## Database

The system uses Supabase PostgreSQL as its backend database.

## Deployment

The system will be deployed using GitHub Pages.
